# Contributing

Thank you for helping improve `skill-fab-unreal-publishing`.

## Development

Install dependencies and run the repository checks before opening a pull request:

```sh
npm ci
npm run verify
```

Keep Fab-specific listing and media guidance here. General publication guidance belongs in `skill-release-publish`; release and portal mechanics belong in `fab-plugin-release-tools`.

## Pull requests

Describe the buyer or publisher problem, summarize the proposed change, and identify any Fab or research sources that support it. Distinguish platform requirements and evidence from operational heuristics. Do not include product-specific media or approval records.
